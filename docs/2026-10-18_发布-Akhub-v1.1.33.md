# 1.1.33 发布记录

发布时间：2026-10-18
主机：Vienna（89.58.17.138），容器部署
镜像：`ghcr.io/hsmirage/akhub:1.1.33`

## 这次改了什么

这是一次**纯前端**的发布：不动网关、调度、存储与升级链路，只改管理后台。

### 1. 删除账号级测试连接，测试连接迁入「模型管理」（用户主诉）

原来的"测试连接"散在三个地方：账号行的「更多操作」、新建账号成功后的弹窗、Key 池的「测试全部 Key」。它们共同的毛病是**离开模型就说不清结果**——测的是"这个账号能不能通"，而真正要回答的是"这个模型在这条链路上能不能通"。

现在照 New API 的做法收进「模型管理」弹窗：

- 工具栏一个「测试连接」，内联展开测试面板（不新开弹窗）；
- 面板里选一个已启用的上游模型，点「开始测试」，返回总体结果 + 延迟 + 逐把 Key 的结果；
- 每行操作列另有「测试」，直接用该行的上游模型名测一次。

测试仍走 `POST /admin/api/accounts/{id}/test`，**后端未改**：用的是已保存的凭据（不触发保存、不受草稿影响），测试通过后仍由后台解除 Key 硬停，前端测完顺手刷新一次全局数据。

### 2. 全站视觉重做：少框、发丝线、安静

原来的界面到处是"卡片套卡片再套表格框"，一屏能看到四五层边界。这次重写了设计令牌与全部组件样式：

- 深色底改 `#0b0b0d`（不再是带紫调的近黑），发丝线统一 `rgba(255,255,255,.06)`，紫色只留给"当前/可点/主操作"；
- `.card`、`.stat`、筛选条、列表工具条全部改为**无边框平面**，区块之间只用留白 + 1px 发丝线；
- 指标从"每张一个框"改成指标带（组间竖线、大号等宽数字）；
- 表头改 11px 大写微标签、无底色；行高收紧；
- 侧栏当前项改左侧 2px 强调条；顶栏操作 ghost 化并合并。

### 3. 文案精简

按"能由控件本身表达的就不再说"逐页清理：页面区块说明压到一行电报式表达，表单 hint 删除重复解释的第二句，弹窗里的三条 callout 各压成一行，术语表 5 条定义缩短。信息量不减——需要展开解释的仍留在 InfoTip 里。

### 4. 排版与动效

- 切页时内容区播一次 180ms 淡入 + 6px 上移，区块按 24ms 依次浮现；刷新数据不触发；
- 行/导航按下态深一档、按钮按下微沉、导航图标 hover 点亮右移 1px；
- 链接按钮改背景渐变宽度动画；抽屉/弹窗/测试面板进出场时长收紧到 150–160ms；
- 全部动效在 `prefers-reduced-motion: reduce` 下降级或关闭。

## 兼容性

- **无数据库结构变更**：可以直接回滚到 1.1.32 读同一个库。
- **无接口变更**：`/admin/api/*` 与 `/v1/*` 全部保持原样，`/accounts/{id}/test` 仍在，只是入口位置变了。
- 前端产物哈希变化，浏览器会重新拉取；`index.html` 仍是 no-cache，不会卡在旧壳子。
