## 修复：开关点击导致抽屉布局跳动

### 现象

账号抽屉里展开「限制与运行时」，点任意开关后，底部「保存」按钮跳到页面
中部，下方露出一大片空白。开关只切一个布尔值，不该影响布局。

### 根因

`.switch` 是 `position: static`，而它里面的隐藏 `<input type="checkbox">`
是 `position: absolute`。绝对定位元素的包含块是**最近的 positioned 祖先**
——在抽屉里落到了 `position: fixed` 的 `.drawer` 上。

修复前实测（1440x700，展开该区后）：

- `input.offsetParent` = `drawer`（应当是开关自己）
- checkbox 被摆到抽屉坐标系 `top=1489`，把 `.drawer` 的 `scrollHeight`
  从 682 撑到 **1658**
- 点击开关时 checkbox 获得焦点，浏览器把最近的可滚动祖先滚进视野；
  `overflow: hidden` 的元素**仍可被程序化滚动**，于是 `.drawer.scrollTop`
  从 0 跳到 **976**
- 抽屉的头/正文/底栏一起上移 976px：保存按钮出现在页面中部，下方留 777px 空白

### 修复

给 `.switch` 建立定位上下文（`position: relative`），并让隐藏 input 用
`inset: 0` 覆盖在开关上（仍不可见、不接收指针）。抽屉不再被撑出可滚动区。

修复后同一路径实测：`offsetParent = switch`，`drawer.scrollHeight = 682`
= `clientHeight`，`drawer.scrollTop` 恒为 0。
